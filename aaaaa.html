新機能を使った一番精度が出る手順 📦 物体を綺麗に3Dモデル化したいとき（WebXR） 1. 「📦 物体スキャン」 を選んで 「⚡ 本物ARスキャン (WebXR)」 を起動。 2. スキャンしたい物に近づいて（0.4〜1.0m）、画面中央の + を物体に合わせて 「🎯 中央の物体をロック」 を押します。物体の周りに黄色い球枠が出ます。 3. 「▶ 自動記録を開始」 を押して（または移動しながら「📸 この視点だけ記録」で）、物体の正面→横→斜め上とスマホを動かします（枠の中だけが記録され、背景の壁や机はカットされます）。 4. 「✅ 完了・3Dへ」 を押すと自動で穴埋めカラーメッシュが生成されます！ 🏠 部屋をスキャンしたいとき（WebXR） 1. 「🏠 部屋スキャン」 を選びます。 2. 画面上部の 中央: ○.○○m を見ながら、スマホを少し左右に動かして 視差OK にした状態で自動記録をONにするか、壁や家具を向き変えるたびに「📸 この視点だけ記録」を押してください。 3. もしお使いの機種で SMOOTH が出て遠くがまだ短めに出る場合は、画面右下の 「距離倍率補正」 スライダーや、3D画面の 「ノイズ除去(確認回数: 2回以上)」 を使うと精度が安定します。 ぜひこちらを試してみて、WebXR画面上部に表示された RAW か SMOOTH かの表示と、中央の距離（m）が実測と合っていたか も教えていただけると、端末のセンサー特性に合わせてさらにピンポイントで追い込めます！ ご指摘ありがとうございます。とても重要なポイントが2つ分かりました。 1. なぜ WebXR で「遠くのものが近くに認識される」のか？ Android Chrome の WebXR Depth Sensing（ARCore）には、仕組み上**「遠くのものが手前に誤認される」明確な原因が3つ**あります。 1. デフォルトが smooth（補間済み）深度マップになっている 前回のコードでは depthTypeRequest を指定していなかったため、ARCore が欠損領域（遠くの壁や模様の薄い場所）を手前にある机や物体の距離で塗りつぶす（Inpainting）処理がかかり、遠くのものまで手前の近い距離に引き寄せられていました。 2. 手前と奥の「境界（エッジ）」の滲み点がそのまま点群になっていた 手前の物体と奥の壁の境界ピクセルは、補間によって「中間の距離」になり、空中にゴミ点として浮き出ます。 3. 移動（視差）ゼロの初期フレームをそのまま固定保存していた ToFセンサー非搭載のスマホでは、ARCore はカメラの移動（視差）から距離を三角測量します。動いていない開始直後は遠くの壁も 1〜2m 付近に誤推定されやすく、前回のコードはそれを最初の0.1秒でそのままボクセルに固定していました。 2. v3 での徹底改善 ＋「🏠 部屋認識」「📦 物体認識」の完全分離 今回の v3 では上記をすべて対策し、さらに**「部屋認識」と「物体認識」を専用アルゴリズムで完全に分けました**。 WebXR の精度・速度改善ポイント - raw 深度優先 ＋ エッジ飛び点（Flying Pixel）除去：raw 対応機では補間のない生データを使用し、隣接ピクセルとの深度差が大きい境界の滲み点を自動カットします。 - 視差（移動）検知 ＋ ウォームアップ ＋ 距離確認HUD：AR画面上部に 「現在の中央距離 (m)」「RAW/SMOOTH」「動きによる視差OK/移動推奨」 をリアルタイム表示。スマホを動かした高精度フレーム優先で記録します。 - ドローコール1本化（15万点事前確保バッファ）：点が増えても一切重くなりません。 2つのスキャンモード（いつでも切替可能） 1. 🏠 部屋スキャンモード（Room） - 測距範囲：0.35m 〜 6.5m（部屋の壁・天井・床まで広く取得） - 解像度：3cm ボクセル（部屋全体を軽快に記録・複数回一致フィルタ付き） 2. 📦 物体スキャンモード（Object） - 測距範囲：0.15m 〜 1.6m（背景の壁を無視） - WebXR ターゲットロック機能：物体に向けて 「🎯 物体をロック」 を押すと、AR空間上のその位置に3D球形スキャン範囲を固定！その範囲内だけを高密度 0.8cm ボクセルで、裏側まで回り込みながらスキャンできます（下の机・床もカット可能）。 - 自動3Dメッシュ化（Surface Nets）：物体スキャン完了後、点群から滑らかな色付き3Dポリゴンメッシュを自動生成して .glb / .ply 保存できます。 - AIカメラモード時：物体タップ / MediaPipe認識枠で対象を自動分離＋エッジ保存平滑化＋立体ソリッド厚み付けを行います。 以下をそのまま index.html に保存してご利用ください。 WEB-LiDAR v3 (部屋 / 物体 分離版)
